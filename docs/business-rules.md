# Зафиксированные бизнес-правила

Этот файл является начальной картой поведения старого приложения. Он будет
расширяться до реализации соответствующих модулей.

## Автомобиль

Автомобиль имеет внутренний учетный номер, государственный номер, модель,
латинское наименование, VIN, страхователя, номер страхового дела, страховую
компанию, исполнителя, даты, смену, комментарий и ссылку на документы.

Новый внутренний номер в старой системе равен максимальному числовому номеру
плюс один.

## Статусы

Приоритет правил:

1. Если автомобиль выдан, статус `DELIVERED`.
2. Если запчастей нет, статус `EMPTY`.
3. Если все запчасти поступили, статус `READY`.
4. Иначе статус `WAITING`.

Запчасть просрочена, если:

- она не поступила;
- ожидаемая дата является корректной датой;
- ожидаемая дата меньше текущей локальной даты.

Статус не должен приниматься от frontend как доверенное поле. Он вычисляется из
состояния автомобиля и запчастей.

## Запчасти

Для запчасти сохраняются:

- автомобиль;
- наименование;
- артикул;
- поставщик;
- ожидаемая дата;
- признак поступления;
- дата поступления.

При переключении в состояние «поступила» дата поступления становится текущей
датой. При отмене поступления дата очищается.

## Выдача

При выдаче автомобиля:

- `delivered = true`;
- дата выдачи становится текущей датой.

При отмене выдачи:

- `delivered = false`;
- дата выдачи очищается.

## Заказ-наряд

Заказ-наряд содержит работы из справочника и произвольные работы. Каждая строка
имеет название, категорию, единицу, количество и цену.

Сумма строки равна:

```text
quantity * price
```

Изменение названия в справочнике не должно изменять ранее сформированный
документ. В новой базе строки документов должны хранить snapshot названия.

## AI-дефектовка

AI создает только рекомендации:

- повреждения;
- тяжесть;
- решение;
- рекомендуемые работы;
- рекомендуемые запчасти;
- уверенность;
- предупреждения.

AI не имеет права:

- автоматически менять автомобиль;
- автоматически создавать запчасти;
- автоматически сохранять заказ-наряд;
- назначать достоверную цену;
- назначать достоверный артикул.

Работы и запчасти переносятся только после ручного подтверждения пользователя.

## Документы

До переписывания генератора необходимо сохранить эталонные файлы:

- заказ-наряд;
- счет;
- акт выполненных работ;
- акт приема;
- акт выдачи;
- печатный комплект.

Новый генератор принимается только после текстового, расчетного и визуального
сравнения с эталонами.
