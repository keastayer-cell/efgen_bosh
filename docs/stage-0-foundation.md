# Этап 0: foundation

## Цель

Создать минимальный запускаемый каркас, не притворяясь, что бизнес-логика уже
перенесена.

## Входит в этап

- Git-репозиторий;
- Java 21;
- Spring Boot;
- PostgreSQL;
- Flyway;
- Spring Security;
- health endpoint;
- базовая схема пользователей, ролей и аудита;
- тесты конфигурации безопасности;
- документация архитектурного решения.

## Не входит в этап

- автомобили;
- запчасти;
- полноценные бизнес-экраны Vue;
- документы;
- импорт Firestore;
- AI;
- реальные пользователи;
- production deployment.

## Критерии завершения

- `mvn test` проходит;
- `mvn package` проходит;
- backend в `app` стартует с PostgreSQL;
- Flyway применяет `V1`;
- `/api/health` доступен без авторизации;
- неизвестный API endpoint не открыт анонимному пользователю;
- секреты не добавлены в Git.

Локальная база запускается как отдельный системный PostgreSQL-сервис, аналогично
`bg_foot_project`. Docker Compose не является частью runtime проекта.

## Следующий этап

Следующим изменением создаётся login shell и API авторизации, но без имитации
готовой серверной бизнес-логики.
