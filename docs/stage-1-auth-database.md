# Этап 1.1: база пользователей и ролей

## Эталон

Структура перенесена из `bg_foot_project`. На этом шаге реализована только база
данных; Java-авторизация и Vue login shell намеренно не добавляются до проверки
миграций.

## Схема

Рабочие таблицы находятся в схеме PostgreSQL `work`:

- `w_user_login` — пользователи входа;
- `w_role` — справочник ролей;
- `w_user_role` — назначения ролей пользователям;
- `w_auth_audit_log` — аудит действий с правами;
- `w_audit_log` — общий аудит бизнес-действий.

Назначение роли хранит:

- пользователя;
- роль;
- пользователя, назначившего роль;
- дату назначения;
- признак активности.

Частичный уникальный индекс запрещает две одинаковые активные роли у одного
пользователя и сохраняет историю отключённых назначений.

## Роли Bosh

- `ADMIN` — управление системой, пользователями и справочниками;
- `OPERATOR` — ежедневная работа с автомобилями, запчастями и документами;
- `VIEWER` — просмотр без изменения данных.

Коды отличаются от футбольного проекта только потому, что предметная область
другая. Устройство справочника и назначений сохранено.
